# AutoDeck — PC agent

The Windows side of [AutoDeck](../README.md). Tauri 2 + SvelteKit (Svelte 5) + Rust.

```sh
npm install
npm run tauri dev    # run in dev mode
npm run tauri build  # produce a release installer
```

See the [project README](../README.md) for what this app does, and [`PROTOCOL.md`](../PROTOCOL.md) for the wire protocol shared with the phone app.
